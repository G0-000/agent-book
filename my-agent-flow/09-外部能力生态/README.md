## 四种接入形态的区别

| 形态 | 谁定义能力 | 隔离边界 | 典型用途 |
|---|---|---|---|
| MCP | 外部服务 | 进程/网络边界 | 数据库、SaaS、内部平台 |
| 插件 | 本机脚本/桥接 | 本机进程与授权 token | 浏览器、桌面、扩展运行时 |
| Skills | 目录、`SKILL.md`、脚本 | 文件与执行权限 | 可复用工作流 |
| A2A | 另一个 Agent | 服务边界 | 跨系统协作 |

## 共同风险与边界

能力发现、OAuth 凭据保护、外部内容不可信处理及运行审批仍需实现和测试。当前文档里的验收目标不是本地现状。
