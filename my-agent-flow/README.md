# EvoFlow 学习与复刻文档 · 多级目录版

> 本目录是把单文件 `doc/EvoFlow-学习规划.md` 按 **Part → Chapter → File** 拆分后的多级文档树。
> 主线内容以《EvoFlow-学习规划》为准；`<EvoFlow 仓库>`（真实源码）、`agent-book`、`AgentFlow` 作为辅助印证；[Harbor404](https://harbor404.fushenlin.com/) 只作通用技术背景参考。

## 一句话定位

用一条可运行的**最小闭环**（配置 → 模型 → Agent → 会话 → 工具 → 流）入门，再逐部分拆解 EvoFlow 的真实工程实现，最终能独立设计一套同类的 Agent 框架。

## 状态图例

**实现状态**回答「本项目代码做到哪」：

- ✅ **最小实现已验收**：本章声明的行为有代码、有测试，测试数字见 [PROGRESS.md](PROGRESS.md)「实现验收记录」。**这表示组件级行为通过，不等于已接入 Gateway / 工具执行器 / system prompt。端到端接线见[完整度审计](00-导论/05-完整度审计-第1至4部分.md)。**
- 🟡 **骨架**：只有章节结构与真实路径，没有完整可运行实现。
- ⬜ **待材料**：仅有目录占位。

**源码核对**回答「EvoFlow 源码读到哪」，与实现状态相互独立：

- ✅ **已核对**：逐行读过对应实现，行为断言有源码依据。
- 🔍 **结构已核对**：路径、类/函数已实测；调用顺序与边界条件未逐行闭合。
- 📄 **原文迁移**：内容来自原始资料，未与源码核对。
