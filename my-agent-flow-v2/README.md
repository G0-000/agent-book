## 怎么用

每一章都是一个独立功能，先跑章级最小闭环，再补完整功能。章节正文固定六节：

`功能与知识点 → 最小调用链 → 代码创建 → 测试 → 完整化 → 边界与验收`

学习顺序按篇走；每一篇内部按章走。遇到“这一章要写什么”不清晰时，先看本篇 README 的篇级闭环，再回到章的 §1 最小验收。
