## 1. 功能与知识点

**功能**：发布、回归与运维。

**知识点如何体现**：CI、迁移、回滚、监控。

**最小验收**：测试 + 构建 + 回滚演练。

## 2. 最小调用链

按「入口 → 调用节点 → 状态变化 → 出口」画一条最小链路；只保留证明本功能所需的最少节点。

- 最小闭环：测试 + 构建 + 回滚演练
- 失败点：入口参数非法、依赖不可用、输出为空。

## 3. 代码创建

- 先按调用链确定文件，不按概念顺序建目录。
- 每个新符号必须写出：谁调用它、它调用谁、输入输出是什么。
- 完整化方向：灰度、备份、告警。

## 4. 测试

- 先写失败用例，再补最小实现。
- 至少三类：正常路径、边界输入、依赖失败。
- 命令格式：`uv run pytest tests/chapters/<本章测试文件> -q`。

## 5. 完整化

灰度、备份、告警。每加一项都要有独立测试；没有测试的扩展不算完成。

## 6. 边界与验收

- 明确写出本章不做什么，不能把组件测试写成端到端完成。
- 验收必须包含：命令、预期输出、常见失败定位。
