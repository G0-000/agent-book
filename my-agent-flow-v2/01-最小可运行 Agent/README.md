# 第 01 篇　最小可运行 Agent

> 状态：📋 篇骨架；6 章。

## 能力域

本篇负责「最小可运行 Agent」这一层能力。每章先跑独立最小闭环，篇末再串成本篇闭环。

## 篇级最小闭环

一条用户消息 → 模型 → 最终回答
