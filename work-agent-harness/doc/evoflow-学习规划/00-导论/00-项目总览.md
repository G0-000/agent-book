## 如何分批喂材料 / How to send batches
1. 每批请说明对应的 Part/Chapter（或直接贴 EvoFlow 的目录、源码片段、文档页）。
2. 我会：**先核对** 已写章节 → **改正** 与 EvoFlow 不一致之处 → **补写** 新章节（含完整业务逻辑与可运行代码，并配测试）→ 更新状态标记。
3. 状态标记：✅ 已与来源核对 · 🟡 自研参考实现、待核对 · ⬜ 待材料。
