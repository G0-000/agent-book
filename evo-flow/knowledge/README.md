## 中文技术文档约定

- 文档以中文解释为主；源码符号、配置字段、API 路径和第三方库名称保持原文。
- 专业术语首次出现采用“英文术语（中文解释）”形式，例如 Agent Runtime（智能体运行时）、Middleware（中间件）、Checkpoint（检查点/状态快照）。
- 文件名采用“英文技术关键词 + 中文说明”；`Harness` 保持英文关键词，Mermaid `.mmd` 文件保持英文名。
- 尚未完成源码研究的框架必须标记 **⬜ 未研究**，不得写入未经证实的结论。

## 使用约定

- 图谱中的实线表示已从入口代码、依赖配置或部署定义中验证的关系；虚线/“可选”表示由环境变量或部署模式决定的关系。
- 每个图后的“证据入口”给出仓库内的主证据文件。代码演进后，请优先复核这些入口而不是只更新文字描述。
